# 🤖 Фандинг Арбитраж Бот

Профессиональный торговый бот для автоматического фандинг-арбитража на криптовалютных биржах.

## 🚀 Возможности

### 📊 **Поддерживаемые биржи:**
- 🟡 **Bybit** - Основная рекомендуемая биржа
- 🟨 **Binance** - Крупнейшая биржа в мире  
- 🟦 **Gate.io** - Высокие ставки фандинга
- 🟩 **KuCoin** - Широкий выбор альткоинов
- ⚫ **OKX** - Профессиональная торговля
- 🔵 **MEXC** - Новые листинги

### ⚡ **Основные функции:**
- **Автоматический фандинг-арбитраж** с настраиваемой задержкой
- **Умное управление рисками** (TP/SL, таймауты ордеров)
- **Мультибиржевая торговля** одновременно на всех биржах
- **Реальное время** - синхронизация с биржевым временем
- **Telegram уведомления** о всех операциях
- **Детальная аналитика** и история сделок

## 🔧 Настройка

### 1. **Регистрация и вход**
- Создайте аккаунт через веб-интерфейс
- Подтвердите email адрес
- Войдите в систему

### 2. **Настройка API ключей**
Перейдите в раздел **"API Ключи"** и добавьте ключи для каждой биржи:

#### 🔑 **Требования к API ключам:**
- ✅ **Включите фьючерсную торговлю**
- ✅ **Разрешите чтение и торговлю**
- ❌ **НЕ включайте вывод средств**
- 🔒 **Добавьте IP сервера в белый список** (рекомендуется)

#### 📋 **Получение API ключей:**
- **Bybit**: [API Management](https://www.bybit.com/app/user/api-management)
- **Binance**: [API Management](https://www.binance.com/en/my/settings/api-management)
- **Gate.io**: [API Keys](https://www.gate.io/myaccount/apiv4keys)
- **KuCoin**: [API Management](https://www.kucoin.com/account/api)
- **OKX**: [API Keys](https://www.okx.com/account/my-api)
- **MEXC**: [API Management](https://www.mexc.com/user/openapi)

### 3. **Конфигурация торговли**
В разделе **"Конфигурация"** настройте параметры для каждой биржи:

#### 💰 **Основные параметры:**
- **Торговая пара**: BTCUSDT, ETHUSDT и др.
- **Размер ордера**: $10 - $10,000
- **Кредитное плечо**: 5-20x (рекомендуется)

#### 🎯 **Управление рисками:**
- **Тейк-профит**: 0.2-0.5% (рекомендуется)
- **Стоп-лосс**: 1-3% (рекомендуется)
- **Направление входа**: Сначала шорт (рекомендуется)

#### ⏰ **Временные параметры:**
- **Задержка после фандинга**: 3000-8000 мс
- **Таймаут ордера**: 5-120 минут

## 🎮 Использование

### 🚀 **Запуск бота:**
1. Убедитесь, что API ключи настроены
2. Проверьте конфигурацию торговли
3. Нажмите **"Запустить арбитраж"**
4. Бот автоматически войдет в позицию перед следующим фандингом

### 🧪 **Тестирование:**
- **"Проверить баланс"** - проверка подключения к бирже
- **"Тестовый ордер"** - проверка торговли без ожидания фандинга
- **"Отменить ордера"** - отмена всех активных ордеров
- **"Закрыть позиции"** - закрытие всех открытых позиций

### 📊 **Мониторинг:**
- **Дашборд** - общая статистика и быстрые действия
- **Позиции** - активные позиции по всем биржам
- **Логи** - детальная история всех операций

## 💡 Стратегия фандинг-арбитража

### 📈 **Как это работает:**
1. **Анализ фандинга** - бот отслеживает ставки фандинга
2. **Вход в позицию** - за несколько секунд до начисления фандинга
3. **Получение фандинга** - получение платежа от противоположной стороны
4. **Выход из позиции** - закрытие по тейк-профиту или стоп-лоссу
5. **Реверс** - открытие противоположной позиции для хеджирования

### 🎯 **Оптимальные условия:**
- **Высокие ставки фандинга** (>0.1%)
- **Низкая волатильность** рынка
- **Достаточная ликвидность** на бирже
- **Стабильное интернет-соединение**

## ⚠️ Риски и предупреждения

### 🚨 **Основные риски:**
- **Рыночный риск** - резкие движения цены
- **Ликвидационный риск** - при высоком плече
- **Технический риск** - сбои API или интернета
- **Фандинговый риск** - изменение ставок фандинга

### 🛡️ **Меры безопасности:**
- **Начинайте с малых сумм** ($10-50)
- **Используйте умеренное плечо** (5-10x)
- **Устанавливайте стоп-лоссы** (1-2%)
- **Мониторьте позиции** регулярно
- **Диверсифицируйте** по биржам и парам
